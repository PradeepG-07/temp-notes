# Statements
A SQL Statement is a complete instruction executed by the database engine to perform an action such as querying, inserting, updating, deleting, or defining data and database objects.

SQL Statements are broadly classified into the following categories:
1. DDL (Data Definition Language)
2. DML (Data Manipulation Language)
3. DQL (Data Query Language)
4. DCL (Data Control Language)
5. TCL (Transaction Control Language)
