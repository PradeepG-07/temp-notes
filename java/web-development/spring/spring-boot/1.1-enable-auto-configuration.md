## Auto Configuration
1. Spring boot automatically does the configuration with help of an annotation called `@AutoConfiguration`,
2. Internally, when spring boot application is started, spring boot checks if `@EnableAutoConfiguration` exists on any class and if it exists then creates all the beans present in the classes annotated with `@AutoConfiguration`.
3. Spring boot comes with some of the pre-built classes annotated with `@AutoConfiguration` for some standard dependencies like `spring-boot-starter-web`, `spring-data` etc.
4. Some of the third party libraries come with their own `@AutoConfiguration` classes to support autoconfiguration.
5. But how spring boot knows when to create these beans.
6. Here comes two more annotations
	1. `@ConditionalOnClass`: This annotation can only be used on classes. Meaning initialize the bean of this class only when the class passed in the `@ConditionalOnClass` exists in the project.
	2. `@ConditionalOnMissingBean`: This annotation can only be used on methods with `@Bean` telling spring boot to create this bean only when the bean doesn't exist in the IoC Container.
    ```java
    @AutoConfiguration
    @ConditionalOnClass(MyLibMain.class)
    public class MyLibConfig{
        @Bean
        @ConditionalOnMissingBean
        public MyLibMain createMyLibMain(){
            return new SimpleMyLibMain();
        }
    }
    ```
