### Objectives
1. Minimise the number of tables 
2. Minimise the storage/disk space without discarding any required information/data
3. Fast retrieval of data

#### Minimise storage space
- To minimise storage meaning there should be no redundant data in the database.
- Inorder to do that we have to learn about functional dependencies, decomposition and normalization.
- These techniques helps to design tables to be less redundant.
